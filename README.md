# REZA.EXE

**An interactive 2D developer portfolio built with Phaser 3, TypeScript, and Vite.**

Explore a pixel-art world, interact with NPCs, and discover my projects, skills, and development journey through a platformer experience.

## 🛠️ Tech Stack

- Phaser 3
- TypeScript
- Vite
- HTML5 / CSS3

## 🚀 Getting Started

```bash
git clone https://github.com/RezaTaheri01/reza-exe.git
cd reza-exe
npm install
npm run dev
```

## 🎮 Controls

| Action | Key |
|---|---|
| Move | A / D or Arrow Keys |
| Jump | Space / W / Up |
| Interact | E |
| Close Dialogue | ESC |

**Touch Supported**
